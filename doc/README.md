# Dashboard Agricole

Ce projet est une application web permettant de gérer les données agricoles. Elle offre des fonctionnalités telles que la gestion des parcelles, des cultures, des alertes, et des prévisions météorologiques.

---

## Fonctionnalités

- **Dashboard** : Vue d'ensemble des données clés (parcelles, alertes, météo).
- **Gestion des parcelles** : Ajout, modification, suppression et visualisation des parcelles.
- **Gestion des cultures** : Suivi des cultures, dates de semis et récolte, et leur statut.
- **Alertes** : Détection automatique des alertes basées sur des règles prédéfinies.
- **Météo** : Consultation des données météorologiques actuelles et historiques.
- **Observations** : Ajout et suivi des observations sur les cultures.

---

## Structure du Projet

- **Frontend** : Développé avec React et Vite, situé dans le dossier `front/`.
- **Backend** : Développé avec Node.js et Express, situé dans le dossier `server/`.
- **Base de données** : Scripts SQL pour la structure et les données dans `BDD/`.
