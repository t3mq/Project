L'interface du dashboard présente plusieurs fonctionnalités pour le bon fonctionnement de votre agriculture.

Elle comprend la météo du jour et une prévision de la semaine. Plusieurs pages sont aussi présente tel que les parcelles, les cultures, la météo, les alertes ou encore les parametres.
Pour cela plusieurs routes ont été crée pour pouvoir récuperer des données de la base de donnée pour la coherence des données et leurs intégrités.
